# Règles d'interface et d'icônes

- **NE JAMAIS UTILISER L'ICÔNE SPARKLES (étincelles/étoiles)** : L'icône `Sparkles` de lucide-react est strictement bannie du projet. Utiliser `Brain`, `Feather`, `Lightbulb`, `Compass`, `BookOpen` ou `Quote` à la place.
- **AUCUN ÉMOJI** : Zéro émoji dans toute l'interface.
- **Polices** : `KGPerfectPenmanship` (titres/boutons) et `Plus Jakarta Sans` (textes/inputs).
- **Catégories** : Vue principale par défaut sous forme de colonnes colorées.
